# 1C:Enterprise Development — Встроенный язык

## Описание

Разработка на встроенном языке (BSL) платформы 1С:Предприятие 8.3. Покрывает модули, процедуры/функции, работу с объектами метаданных (справочники, документы, регистры), паттерны БСП, типизацию и обработку ошибок.

## Когда использовать

- Написание/модификация модулей объектов, форм, менеджеров
- Разработка внешних обработок и отчётов (EPF/ERF)
- Рефакторинг BSL-кода
- Разработка расширений конфигурации (CFE)
- Интеграция с внешними системами через HTTP/COM/веб-сервисы
- Работа с БСП (библиотека стандартных подсистем)

### 4. Работа с формами — обработчики событий

```
// Модуль формы — ПриСозданииНаСервере
//
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    
    // Установка начальных значений
    Объект.Дата = ТекущаяДата();
    
    // Условное оформление
    ЭлементОформления = УсловноеОформление.Элементы.Добавить();
    Отбор = ЭлементОформления.Отбор.Элементы.Добавить(
        Тип("ЭлементОтбораКомпоновкиДанных"));
    Отбор.ЛевоеЗначение = Новый ПолеКомпоновкиДанных("Объект.Сумма");
    Отбор.ВидСравнения = ВидСравненияКомпоновкиДанных.Больше;
    Отбор.ПравоеЗначение = 100000;
    
    Оформление = ЭлементОформления.Оформление.Элементы.Найти("ЦветФона");
    Оформление.Значение = WebЦвета.СветлоЖёлтый;
    Оформление.Использование = Истина;
    
    // Доступность реквизитов
    Элементы.Контрагент.Доступность = Объект.ВидОперации <> 
        Перечисления.ВидыОпераций.Внутреннее;
    
КонецПроцедуры

// Модуль формы — Клиент
//
&НаКлиенте
Процедура ТоварыНоменклатураПриИзменении(Элемент)
    
    ТекущиеДанные = Элементы.Товары.ТекущиеДанные;
    Если ТекущиеДанные = Неопределено Тогда
        Возврат;
    КонецЕсли;
    
    // Асинхронный вызов сервера
    Результат = ПолучитьЦенуНоменклатурыНаСервере(
        ТекущиеДанные.Номенклатура, ТекущаяДата());
    ТекущиеДанные.Цена = Результат;
    
    // Пересчёт суммы
    ТекущиеДанные.Сумма = ТекущиеДанные.Количество * ТекущиеДанные.Цена;
    
    // Обновление итогов
    СуммаДокумента = Объект.Товары.Итог("Сумма");
    
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьЦенуНоменклатурыНаСервере(Номенклатура, Дата)
    
    Запрос = Новый Запрос;
    Запрос.Текст = 
    "ВЫБРАТЬ ПЕРВЫЕ 1
    |    ЦеныНоменклатуры.Цена
    |ИЗ
    |    РегистрСведений.ЦеныНоменклатуры.СрезПоследних(&Дата, 
    |        Номенклатура = &Номенклатура) КАК ЦеныНоменклатуры";
    
    Запрос.УстановитьПараметр("Дата", Дата);
    Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
    
    РезультатЗапроса = Запрос.Выполнить();
    Если РезультатЗапроса.Пустой() Тогда
        Возврат 0;
    КонецЕсли;
    
    Выборка = РезультатЗапроса.Выбрать();
    Выборка.Следующий();
    Возврат Выборка.Цена;
    
КонецФункции
```

        ,

// === ВызватьИсключение с деталями ===

## Лучшие практики

- **Минимум серверных вызовов в цикле** — группируйте данные, используйте временные таблицы
- **Режим совместимости** — указывайте `// @strict` или `// @compatibility` для явного контроля
- **Типизация переменных** — объявляйте через `Перем` в модуле объекта/формы
- **Директива РАЗРЕШЕННЫЕ** — всегда добавляйте в запросы (RLS)
- **БСП-модули** — используйте общие модули вместо дублирования кода
- **Асинхронные методы** — `НачатьВыполнениеФоновогоЗадания()` для долгих операций
- **Валидация перед записью** — `ПроверитьЗаполнение()` + `ПередЗаписью()`

## Антипаттерны

- ❌ **Запрос в цикле** — O(N²), выносите в один запрос с временной таблицей
- ❌ **Выборка.Следующий() в цикле по всем документам** — читайте пакетно
- ❌ **Движения вручную без проверки** — всегда проверяйте дубли и остатки
- ❌ **Сообщение без поля** — поле помогает навигации к ошибке в форме
- ❌ **Пустые catch{}** — всегда логируйте ошибку
- ❌ **Прямое открытие формы по ссылке** — используйте `ОткрытьФорму()` с параметрами
- ❌ **Хардкод периодов** — используйте функции из БСП `ОбщегоНазначения.РабочаяДатаНачалоДня()`
