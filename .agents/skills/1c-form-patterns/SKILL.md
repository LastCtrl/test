# 1C:Enterprise — Паттерны компоновки управляемых форм

## Описание

Справочник типовых паттернов дизайна управляемых форм 1С. Архетипы форм (документ, обработка, справочник, список), конвенции именования, иерархия групп, продвинутые приёмы компоновки.

## Когда использовать

- Проектирование управляемой формы (выбор архетипа)
- Расположение элементов управления на форме
- Определение иерархии групп и страниц
- Настройка событий формы (OnCreateAtServer, OnOpen и др.)
- Модификация стандартных форм (Список, Элемент)

## Инструкции

### Архетипы форм

#### Форма документа

```
Шапка (horizontal, 2 колонки)
├─ Левая (vertical): НомерДата (H: Номер + Дата "от"), Контрагент, Договор
├─ Правая (vertical): Организация, Подразделение, ЦеныИВалюта (надпись-ссылка)
Страницы (pages)
├─ Товары: таблица Объект.Товары
├─ Услуги: таблица Объект.Услуги (опционально)
└─ Дополнительно: прочие реквизиты
Подвал (vertical)
├─ Итоги (horizontal): Всего, НДС, Скидка
└─ КомментарийОтветственный (horizontal): Комментарий + Ответственный
```

**События:** OnCreateAtServer, OnReadAtServer, OnOpen, BeforeWriteAtServer, AfterWriteAtServer, AfterWrite, NotificationProcessing
**Свойства:** `autoTitle=false`

#### Форма обработки (DataProcessor)

```
Параметры (vertical)
├─ Группа полей ввода (Организация, Период, режимы работы)
├─ Информационные надписи (label, hyperlink)
Рабочая область
├─ Таблица данных или Pages с вкладками
Кнопки действий
├─ Выполнить / Применить (defaultButton)
├─ Закрыть (stdCommand: Close)
```

**События:** OnCreateAtServer, OnOpen, NotificationProcessing
**Свойства:** `windowOpeningMode=LockOwnerWindow` (если диалог), `autoTitle=false`

#### Форма списка справочника/документа

```
КоманднаяПанель (horizontal)
├─ Создать, ПометитьНаУдаление, Изменить, Скопировать, ФильтрыИПоиск
ДинамическийСписок (main area)
├─ ТаблицаСписка с колонками
└─ Группировки (опционально)
```

**События:** OnCreateAtServer, OnOpen, ListChoiceProcessing, DecisionProcessing

### Типы групп

| Тип | Назначение | Визуально |
|-----|-----------|-----------|
| `ГруппаКолонок` | Объединение колонок таблицы | Вертикальная группа в таблице |
| `ГруппаСтраниц` | Страницы (вкладки) | Вкладки |
| `ОбычнаяГруппа` | Контейнер для элементов | Рамка с заголовком |
| `ГруппаКнопок` | Кнопки в панели | Кнопки |

### Иерархия групп (порядок важен)

```
Форма
├─ ГруппаШапка (ОбычнаяГруппа, horizontal)
│  ├─ ЛеваяЧасть (ОбычнаяГруппа, vertical)
│  └─ ПраваяЧасть (ОбычнаяГруппа, vertical)
├─ Страницы (ГруппаСтраниц)
│  ├─ СтраницаТовары (ГруппаСтраницы)
│  └─ СтраницаДополнительно (ГруппаСтраницы)
└─ ГруппаПодвал (ОбычнаяГруппа, vertical)
```

### Именование элементов

| Тип элемента | Префикс | Пример |
|-------------|---------|--------|
| Поле ввода | `ПолеВвода` | `ПолеВводаКонтрагент` |
| Таблица | `Таблица` | `ТаблицаТовары` |
| Кнопка | `Команда` | `КомандаЗаписатьИЗакрыть` |
| Надпись | `Декорация` | `ДекорацияЗаголовок` |
| Группа | `Группа` | `ГруппаШапка` |
| Страница | `Страница` | `СтраницаТовары` |

### Стандартные формы

```bsl
// Открытие формы документа
ПараметрыФормы = Новый Структура("Ключ", Объект.Ссылка);
ОткрытьФорму("Документ.РеализацияТоваровУслуг.ФормаОбъекта", ПараметрыФормы);

// Открытие формы списка с отбором
ПараметрыФормы = Новый Структура("Отбор", Новый Структура("Организация", Организация));
ОткрытьФорму("Документ.РеализацияТоваровУслуг.ФормаСписка", ПараметрыФормы);

// Открытие формы выбора
ПараметрыФормы = Новый Структура("РежимВыбора", Истина);
ОткрытьФорму("Справочник.Контрагенты.ФормаВыбора", ПараметрыФормы);
```

## Лучшие практики

- **Минимум элементов на форме** — убирайте лишнее, группируйте по функциональности
- **Порядок элементов** — сверху вниз, слева направо (как пользователь читает)
- **Группировки** — используйте `ГруппаКолонок` для связанных полей
- **Страницы** — выносите малоиспользуемое на вкладки «Дополнительно»
- **Кнопки действий** — внизу формы, в отдельной группе
- **Заголовок формы** — `autoTitle=false` + переопределение в `OnCreateAtServer`
- **Обработчики событий** — не пишите логику в `OnOpen`, используйте `OnCreateAtServer`
