# 1C:Enterprise — 1С:Напарник (MCP-инструменты анализа кода)

## Описание

MCP-сервер **1c-naparnik** — интеграция с API 1С:Напарник (code.1c.ai). 12 инструментов: 6 для анализа/модификации BSL-кода, 6 для поиска по документации и базе знаний ИТС.

## Когда использовать

- Нужно проверить качество BSL-кода (стиль, архитектура, стандарты)
- Нужно проверить код на синтаксические ошибки, логические проблемы, антипаттерны
- Нужно получить code review по стандартам ИТС
- Нужно найти методологическую статью или стандарт на ИТС
- Нужно прочитать документ ИТС по ID
- Нужно найти информацию в документации платформы
- Нужно сравнить изменения между версиями платформы
- Нужно найти информацию по конкретной конфигурации (ERP, ЗУП)

## Инструкции

### Проверка доступности

Сервер работает через Docker на порту 8007. Если недоступен:

```bash
cd <путь к 1c-code-checker> && docker compose up -d
```

### Инструменты анализа кода (6)

| Инструмент | Назначение |
|------------|-----------|
| `ask_1c_ai` | Свободный вопрос к ИИ по 1С (основной) |
| `check_1c_code` | Синтаксис + логика + производительность |
| `review_1c_code` | Code review по стандартам ИТС |
| `rewrite_1c_code` | Улучшение кода ИИ (ИИ сам решает что) |
| `modify_1c_code` | Модификация по инструкции пользователя |
| `explain_1c_syntax` | Объяснение конкретного ключевого слова BSL |

### Инструменты документации (6)

| Инструмент | Назначение |
|------------|-----------|
| `its_help` | Поиск по ИТС (стандарты, статьи) |
| `fetch_its` | Чтение документа ИТС по ID |
| `search_1c_documentation` | Документация платформы (по версии) |
| `onec_help` | Документация платформы (последняя версия) |
| `diff_1c_documentation_versions` | Сравнение версий платформы |
| `config_help` | Документация конфигураций (ERP, ЗУП, БП) |

### Типичные workflow

**Проверка качества BSL-кода:**

```
1. ask_1c_ai(question="<код>")         — быстрая проверка (ОБЯЗАТЕЛЬНО)
2. check_1c_code(code="<код>")         — синтаксис + логика (при необходимости)
3. review_1c_code(code="<код>")        — стиль и стандарты ИТС (перед коммитом)
```

**Поиск стандарта ИТС:**

```
1. its_help(query="обработка исключений") — найти документы
2. fetch_its(id="its-...-hdoc")           — прочитать нужный
```

**Проверка API платформы:**

```
search_1c_documentation(query="HTTPСоединение", version="8.3.25")
# или
onec_help(query="HTTPСоединение")
```

### Разграничение с другими MCP

| Задача | Инструмент |
|--------|-----------|
| Синтаксис BSL | `check_1c_code` |
| API платформы (офлайн, быстро) | bsl-platform-help (`search`) |
| API платформы (с версией, полнее) | `search_1c_documentation` |
| Стандарты ИТС | `its_help` + `fetch_its` |
| Документация конфигураций | `config_help` |
| Функции БСП | 1c-mcp_ssl_server (`ssl_search`) |

## Лучшие практики

- **Всегда проверяй `ask_1c_ai` после написания/изменения BSL-кода**
- **Напарник даёт false positives** — правь код только после подтверждения существования метода
- **Используй `its_help`** для поиска стандартов — это уникальная возможность
