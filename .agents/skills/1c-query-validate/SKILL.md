# 1C:Enterprise — Проверка запросов по выгрузке конфигурации

## Описание

Проверка текста запроса 1С по выгрузке конфигурации: существуют ли таблицы, табличные части, виртуальные таблицы регистров и поля. Работает без EDT, без платформы и без базы — по индексу от 1c-config-index. Ловит опечатки в именах до того, как запрос попадёт в базу.

## Когда использовать

- Написали запрос и хотите проверить его перед выполнением
- Переименовали объект/реквизит — нужно найти сломанные запросы
- Миграция конфигурации — проверка всех запросов на актуальность имён
- Отладка ошибки «Таблица не найдена» или «Поле не определено»

## Инструкции

### Команда

```powershell
powershell.exe -NoProfile -File ".agents/skills/1c-query-validate/scripts/query-validate.ps1" -QueryPath "запрос.txt" -IndexPath ".cache/index.json"
```

```bash
python skills/1c-query-validate/scripts/query-validate.py -QueryPath запрос.txt -IndexPath .cache/index.json
```

### Параметры

| Параметр | Обяз. | Описание |
|----------|:-----:|----------|
| `QueryPath` | * | Файл с текстом запроса |
| `Query` | * | Текст запроса прямо в аргументе |
| `IndexPath` | да | Индекс от `1c-config-index` |
| `Detailed` | нет | Показать счётчики даже когда есть замечания |
| `MaxErrors` | нет | Не выводить больше N замечаний (по умолчанию 30) |

\* Нужен ровно один из `QueryPath` и `Query`.

### Что проверяется

**Имена метаданных** — где угодно в тексте:
- `Справочник.Контрагенты` → проверяется существование объекта
- `Документ.Накладная.Товары` → проверяется табличная часть
- `РегистрНакопления.Остатки.ОстаткиИОбороты` → проверяется виртуальная таблица

**Допустимые виртуальные таблицы регистров:**

| Регистр | ВТ |
|---------|---|
| Накопления | Остатки, Обороты, ОстаткиИОбороты, ВТ (с названием) |
| Сведений | СрезПоследних, СрезПервых |
| Бухгалтерии | Остатки, Обороты, ОстаткиИОбороты, ОборотыДтКт, ДвиженияССубконто |
| Расчета | ФактическийПериодДействия, БазаНачисленияДляКоличества, БазаНачисленияДляСуммы |

### Workflow

```bash
# 1. Собрать индекс
python skills/1c-config-index/scripts/config-index.py -ConfigPath src -OutFile .cache/index.json

# 2. Проверить запрос
python skills/1c-query-validate/scripts/query-validate.py -QueryPath запрос.txt -IndexPath .cache/index.json
```

### Формат вывода

```
✓ Запрос корректен (проверено объектов: 3, полей: 12)
✗ Ошибки:
  строка 3: Справочник.Номеклатура — объект не найден (возможно: Номенклатура)
  строка 7: Документ.Реализация.СуммаНДС — поле не найдено в документе
```

## Примеры

```bash
# Проверить запрос из файла
python query-validate.py -QueryPath запрос.txt -IndexPath .cache/index.json

# Проверить запрос из аргумента
python query-validate.py -Query "ВЫБРАТЬ Ссылка ИЗ Справочник.Контрагенты" -IndexPath .cache/index.json

# С подробным выводом
python query-validate.py -QueryPath запрос.txt -IndexPath .cache/index.json --Detailed
```

## Лучшие практики

- **Перед выполнением** — всегда проверяй имена в запросе
- **Индекс актуальный** — пересобирай после каждого изменения конфигурации
- **Комбинируй с bsl-validate** — полная проверка кода + запросов
