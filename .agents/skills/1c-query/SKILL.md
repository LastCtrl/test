# 1C:Enterprise — Язык запросов

## Описание

Составление и оптимизация запросов на языке запросов 1С:Предприятие 8.3. Покрывает синтаксис (ВЫБРАТЬ/ИЗ/ГДЕ), соединения, временные таблицы, виртуальные таблицы регистров (остатки, обороты, срезы), агрегатные функции и оптимизацию производительности.

## Когда использовать

- Составление запросов для получения/фильтрации/агрегации данных из 1С-базы
- Построение отчётов и сводок
- Оптимизация медленных запросов
- Отладка ошибок в запросах (неверные имена таблиц, поля, типы)
- Работа с виртуальными таблицами регистров накопления/сведений/бухгалтерии
- Подготовка данных для выгрузки/обмена

## Инструкции

### 1. Базовый синтаксис

```
// Минимальный запрос
ВЫБРАТЬ Ссылка, Наименование
ИЗ Справочник.Контрагенты
ГДЕ НЕ ПометкаУдаления

// С выборкой полей, сортировкой и лимитом
ВЫБРАТЬ ПЕРВЫЕ 100
    Ссылка КАК Документ,
    Дата,
    Номер,
    СуммаДокумента КАК Сумма
ИЗ Документ.РеализацияТоваровУслуг
ГДЕ Дата >= &НачалоПериода
  И Дата <= &КонецПериода
УПОРЯДОЧИТЬ ПО Дата УБЫВ
```

**Ключевые слова:**

| Ключевое слово | Значение |
|---------------|----------|
| `ВЫБРАТЬ` | SELECT — начало запроса (обязательное) |
| `РАЗРЕШЕННЫЕ` | Учитывать RLS (рекомендуется всегда) |
| `РАЗЛИЧНЫЕ` | DISTINCT — убрать дубли |
| `ПЕРВЫЕ N` | Вернуть первые N строк (аналог LIMIT) |
| `ИЗ` | FROM — источники данных |
| `ГДЕ` | WHERE — фильтр строк |
| `СГРУППИРОВАТЬ ПО` | GROUP BY |
| `ИМЕЮЩИЕ` | HAVING — фильтр групп |
| `ОБЪЕДИНИТЬ [ВСЕ]` | UNION [ALL] |
| `УПОРЯДОЧИТЬ ПО` | ORDER BY (`ВОЗР`=ASC, `УБЫВ`=DESC) |
| `ИТОГИ` | TOTALS — итоговые подстроки |

### 2. Имена таблиц из метаданных

**Никогда не угадывайте имена объектов и полей!** Сначала получите метаданные через `get_metadata`, затем составляйте запрос.

| Тип объекта | Имя таблицы | Пример |
|-------------|-------------|--------|
| Справочник | `Справочник.<Имя>` | `Справочник.Номенклатура` |
| Документ | `Документ.<Имя>` | `Документ.РеализацияТоваровУслуг` |
| Табличная часть документа | `Документ.<Имя>.<Раздел>` | `Документ.РеализацияТоваровУслуг.Товары` |
| Регистр накопления | `РегистрНакопления.<Имя>` | `РегистрНакопления.ОстаткиТоваров` |
| Регистр сведений | `РегистрСведений.<Имя>` | `РегистрСведений.КурсыВалют` |
| Регистр бухгалтерии | `РегистрБухгалтерии.<Имя>` | `РегистрБухгалтерии.Хозрасчетный` |
| План счетов | `ПланСчетов.<Имя>` | `ПланСчетов.Хозрасчетный` |

### 3. Виртуальные таблицы регистров

**КРИТИЧЕСКИ ВАЖНО:** Фильтры виртуальных таблиц передаются как параметры вызова, НЕ в WHERE!

```
// === Регистр накопления ===

// Текущие остатки (без даты = последние)
ВЫБРАТЬ Номенклатура, КоличествоОстаток
ИЗ РегистрНакопления.ОстаткиТоваров.Остатки(, Номенклатура = &Ном) КАК Ост

// Остатки на дату
ВЫБРАТЬ Номенклатура, КоличествоОстаток
ИЗ РегистрНакопления.ОстаткиТоваров.Остатки(&Дата, Склад = &Склад) КАК Ост

// Обороты за период
ВЫБРАТЬ Номенклатура, КоличествоПриход, КоличествоРасход
ИЗ РегистрНакопления.ОстаткиТоваров.Обороты(&НачДата, &КонДата, , Номенклатура = &Ном) КАК Об

// Остатки и обороты
ВЫБРАТЬ Номенклатура, 
    КоличествоНачальныйОстаток, КоличествоПриход, 
    КоличествоРасход, КоличествоКонечныйОстаток
ИЗ РегистрНакопления.ОстаткиТоваров.ОстаткиИОбороты(&НачДата, &КонДата, , , ) КАК Об


// === Регистр сведений ===

// Срез последних (актуальные значения)
ВЫБРАТЬ Валюта, Курс, Кратность
ИЗ РегистрСведений.КурсыВалют.СрезПоследних(&Дата, Валюта = &Валюта) КАК Курсы

// Срез первых
ВЫБРАТЬ Валюта, Курс
ИЗ РегистрСведений.КурсыВалют.СрезПервых(&Дата, ) КАК Курсы


// === Регистр бухгалтерии (Хозрасчетный) ===

// Остатки по счету
ВЫБРАТЬ Счет, Субконто1, СуммаОстатокДт, СуммаОстатокКт
ИЗ РегистрБухгалтерии.Хозрасчетный.Остатки(&Период, Счет = &Счет, , ) КАК Бух

// Обороты Дт/Кт за период
ВЫБРАТЬ СчетДт, СчетКт, СуммаОборотДт, СуммаОборотКт
ИЗ РегистрБухгалтерии.Хозрасчетный.ОборотыДтКт(&НачДата, &КонДата, , , , , , ) КАК Бух

// Остатки и обороты с детализацией
ВЫБРАТЬ Счет, Субконто1, 
    СуммаНачальныйОстатокДт, СуммаОборотДт, СуммаОборотКт, 
    СуммаКонечныйОстатокДт
ИЗ РегистрБухгалтерии.Хозрасчетный.ОстаткиИОбороты(
    &НачДата, &КонДата, Авто, , Счет = &Счет, , ) КАК Бух
```

**Суффиксы ресурсов регистра накопления:**

| Виртуальная таблица | Суффикс | Пример |
|---------------------|---------|--------|
| `.Остатки()` | `<Ресурс>Остаток` | `КоличествоОстаток` |
| `.Обороты()` | `<Ресурс>Оборот` | `КоличествоОборот` |
| `.ОстаткиИОбороты()` | `<Ресурс>НачальныйОстаток` | `КоличествоНачальныйОстаток` |
| `.ОстаткиИОбороты()` | `<Ресурс>Приход` | `КоличествоПриход` |
| `.ОстаткиИОбороты()` | `<Ресурс>Расход` | `КоличествоРасход` |
| `.ОстаткиИОбороты()` | `<Ресурс>КонечныйОстаток` | `КоличествоКонечныйОстаток` |

### 4. Соединения (JOIN)

```
ВЫБРАТЬ
    Док.Ссылка КАК Документ,
    Док.Дата,
    Конт.Наименование КАК Контрагент,
    Орг.Наименование КАК Организация
ИЗ Документ.РеализацияТоваровУслуг КАК Док
    ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК Конт
    ПО Док.Контрагент = Конт.Ссылка
    ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Организации КАК Орг
    ПО Док.Организация = Орг.Ссылка
ГДЕ Док.Проведен
  И Док.Дата >= &НачалоПериода
```

**Типы соединений:**

| Тип | Синтаксис | Когда использовать |
|-----|-----------|-------------------|
| Внутреннее | `ВНУТРЕННЕЕ СОЕДИНЕНИЕ ... ПО` | Только совпавшие строки |
| Левое | `ЛЕВОЕ [ВНЕШНЕЕ] СОЕДИНЕНИЕ ... ПО` | Все строки левой таблицы |
| Правое | `ПРАВОЕ [ВНЕШНЕЕ] СОЕДИНЕНИЕ ... ПО` | Все строки правой таблицы |
| Полное | `ПОЛНОЕ [ВНЕШНЕЕ] СОЕДИНЕНИЕ ... ПО` | Все строки обеих таблиц |

### 5. Временные таблицы

```
// Шаг 1: Сбор данных во временную таблицу
ВЫБРАТЬ Ссылка КАК Номенклатура
ПОМЕСТИТЬ ВТ_ТоварыСВысокойЦеной
ИЗ Справочник.Номенклатура
ГДЕ Цена > &ПорогЦены
ИНДЕКСИРОВАТЬ ПО Номенклатура
;

// Шаг 2: Использование временной таблицы в основном запросе
ВЫБРАТЬ
    Ост.Номенклатура,
    Ост.КоличествоОстаток
ИЗ РегистрНакопления.ОстаткиТоваров.Остатки(, 
    Номенклатура В (ВЫБРАТЬ Номенклатура ИЗ ВТ_ТоварыСВысокойЦеной)
) КАК Ост
```

**Правила:**
- Разделяйте запросы пакета символом `;`
- `ПОМЕСТИТЬ <Имя>` — сразу после полей SELECT, перед ИЗ
- `ИНДЕКСИРОВАТЬ ПО <Поле>` — после запроса для таблиц >1000 строк
- **НИКОГДА** не создавайте/удаляйте временные таблицы в цикле
- Минимизируйте количество полей и строк во временных таблицах

### 6. Агрегатные функции и GROUP BY

```
ВЫБРАТЬ
    Док.Контрагент КАК Контрагент,
    СУММА(Док.СуммаДокумента) КАК СуммаИтого,
    КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Док.Ссылка) КАК КоличествоДокументов,
    МИНИМУМ(Док.Дата) КАК ДатаПервого,
    МАКСИМУМ(Док.Дата) КАК ДатаПоследнего,
    СРЕДНЕЕ(Док.СуммаДокумента) КАК СредняяСумма
ИЗ Документ.РеализацияТоваровУслуг КАК Док
ГДЕ Док.Проведен
  И Док.Дата МЕЖДУ &НачалоГода И &КонецГода
СГРУППИРОВАТЬ ПО Док.Контрагент
ИМЕЮЩИЕ СУММА(Док.СуммаДокумента) > &ПорогСуммы
УПОРЯДОЧИТЬ ПО СуммаИтого УБЫВ
```

## Лучшие практики

- **Всегда используйте `РАЗРЕШЕННЫЕ`** — уважайте ролевую модель (RLS)
- **Параметризуйте** — внешние значения через `&Параметр`, никогда через конкатенацию строк
- **Именуйте алиасы понятно** — `Конт`, `Док`, `Ост` вместо `Р`, `Т`, `С`
- **Временные таблицы вместо подзапросов** — для повторяющихся подзапросов
- **Индексируйте** — временные таблицы >1000 строк с `ИНДЕКСИРОВАТЬ ПО`
- **Виртуальные таблицы с параметрами** — фильтры в параметрах вызова, не в WHERE
- **ВЫБОР (CASE) только в дополнительных условиях** — не в индексируемых
- **ПЕРВЫЕ N** — вместо LIMIT (в 1С нет LIMIT)
- **ЕСТЬNULL** — для полей из LEFT JOIN, которые могут быть NULL

## Антипаттеры

- ❌ **Запрос в цикле** — O(N²), выносите в один запрос с параметром `В (...)`
- ❌ **`*` без необходимости** — выбирает только реальные поля, не виртуальные; указывайте нужные
- ❌ **`ИЛИ` в WHERE** — заменяйте на `В (...)` или `ОБЪЕДИНИТЬ ВСЕ`
- ❌ **Вложенные JOIN** — заменяйте на временные таблицы
- ❌ **`Ссылка В ИЕРАРХИИ (ПустаяСсылка)`** — очень медленно
- ❌ **Фильтрация в WHERE для виртуальных таблиц** — используйте параметры вызова
- ❌ **`ПОДОБНО "%шаблон"`** — не использует индексы, только `"шаблон%"`
- ❌ **ДвиженияССубконто без Субконто** — смещается позиционный список параметров
