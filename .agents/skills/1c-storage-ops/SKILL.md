# 1C:Enterprise — Операции с хранилищем конфигурации

## Описание

Работа с хранилищем конфигурации 1С (не Git!) через пакетный запуск платформы: отчёт по версиям, захват и снятие захвата, обновление, помещение, выгрузка в CF, подключение и отключение базы. Основной механизм совместной работы в Конфигураторе.

## Когда использовать

- Захватить объекты для редактирования в хранилище
- Поместить изменения в хранилище (commit)
- Получить изменения из хранилища (update)
- Снять захват (unlock)
- Подключить/отключить базу от хранилища
- Посмотреть историю версий хранилища
- Выгрузить конфигурацию хранилища в CF

## Инструкции

### Команда

```powershell
powershell.exe -NoProfile -File ".agents/skills/1c-storage-ops/scripts/storage-ops.ps1" -Operation <операция> [параметры]
```

### Операции

| Операция | Что делает |
|----------|-----------|
| `status` | Отчёт по версиям хранилища в файл. Самая дешёвая проверка |
| `lock` | Захватить объекты для редактирования |
| `update` | Обновить локальную конфигурацию из хранилища |
| `commit` | Поместить изменения в хранилище |
| `unlock` | Отменить захват |
| `dump` | Выгрузить конфигурацию хранилища в CF |
| `bind` | Подключить информационную базу к хранилищу |
| `unbind` | Отключить информационную базу от хранилища |

### Параметры

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `-Operation <имя>` | да | Одна из операций выше |
| `-V8Path <путь>` | нет | Каталог bin платформы или полный путь к 1cv8.exe |
| `-InfoBasePath <путь>` | * | Файловая база |
| `-InfoBaseServer <сервер>` | * | Сервер 1С |
| `-InfoBaseRef <имя>` | * | Имя базы на сервере |
| `-UserName <имя>` | нет | Пользователь базы |
| `-Password <пароль>` | нет | Пароль пользователя базы |
| `-RepositoryPath <путь>` | да | Каталог хранилища конфигурации |
| `-RepositoryUser <имя>` | нет | Пользователь хранилища |
| `-RepositoryPassword <пароль>` | нет | Пароль пользователя хранилища |
| `-Objects "имя,имя"` | ** | Полные имена объектов через запятую |
| `-IncludeChildObjects` | нет | Захватывать вместе с подчинёнными объектами |
| `-Comment <текст>` | *** | Комментарий помещения |
| `-KeepLocked` | нет | Оставить объекты захваченными после помещения |
| `-OutputFile <путь>` | **** | Файл отчета для `status`, CF-файл для `dump` |

### Порядок работы (рабочий цикл)

```
1. update   — начать с актуального состояния
2. lock     — захватить нужные объекты
3. если получены объекты из хранилища — выгрузи их заново (dump -Mode Partial)
4. правки в исходниках
5. commit   — поместить изменения с комментарием
6. unlock   — снять захват
```

**Что захватывается:** объект + его формы, макеты и команды. Реквизиты, ТЧ — не отдельные объекты.

| Что правишь | Что захватывать |
|-------------|----------------|
| Реквизит, ТЧ, модуль объекта | сам объект: `Справочник.Контрагенты` |
| Существующую форму, макет | её саму: `Справочник.Контрагенты.Форма.ФормаЭлемента` |
| Добавляешь новую форму | объект-владельца; при помещении назови и новый объект |
| Добавляешь новый объект | только корень: `Конфигурация` |

### Имена объектов

- Объект: `Справочник.Номенклатура`
- Форма: `Документ.ЗаказПокупателя.Форма.ФормаДокумента`
- Макет: `Справочник.Номенклатура.Макет.Печать`
- Корень: `Конфигурация`

## Примеры

```powershell
# Захватить справочник с подчинёнными объектами
powershell.exe -NoProfile -File ".agents/skills/1c-storage-ops/scripts/storage-ops.ps1" -Operation lock -InfoBasePath "C:\Bases\MyDB" -RepositoryPath "C:\Repo\MyCfg" -Objects "Справочник.Номенклатура" -IncludeChildObjects

# Поместить изменения
powershell.exe -NoProfile -File ".agents/skills/1c-storage-ops/scripts/storage-ops.ps1" -Operation commit -InfoBasePath "C:\Bases\MyDB" -RepositoryPath "C:\Repo\MyCfg" -Objects "Справочник.Номенклатура" -Comment "Добавлен реквизит Артикул"

# Обновить из хранилища
powershell.exe -NoProfile -File ".agents/skills/1c-storage-ops/scripts/storage-ops.ps1" -Operation update -InfoBasePath "C:\Bases\MyDB" -RepositoryPath "C:\Repo\MyCfg"

# Отчёт по версиям
powershell.exe -NoProfile -File ".agents/skills/1c-storage-ops/scripts/storage-ops.ps1" -Operation status -InfoBasePath "C:\Bases\MyDB" -RepositoryPath "C:\Repo\MyCfg" -OutputFile "C:\Temp\status.txt"
```

## Лучшие практики

- **Всегда начинай с update** — правки должны опираться на актуальное состояние
- **Захватывай минимум** — чем шире захват, тем больше конфликтов
- **Читай вывод** — нулевой код не означает, что ничего не изменилось
- **Подтверждение** — перед `lock -All` и `unlock -Force` спрашивай пользователя
- **Расширения** — у расширения своё хранилище, указывай `-Extension`
