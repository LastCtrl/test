# 1C:Enterprise — Шаги Vanessa Automation (BDD-тестирование)

## Описание

Реестр из **1569 шагов** Vanessa Automation с описаниями и типами. Позволяет найти нужный шаг по смыслу и проверить готовый сценарий .feature перед запуском. Предотвращает ошибки «модель сочинила шаг, которого в Vanessa нет».

## Когда использовать

- Пишешь новый сценарий Vanessa — **сначала найди шаги**, потом составляй из найденного
- Правишь чужой сценарий и не уверен, существует ли шаг
- Получил сценарий от заказчика — проверь перед запуском
- Нужно понять, каким шагом делается конкретное действие (открыть форму, заполнить поле, проверить значение)

## Когда НЕ использовать

- Юнит-тесты на YaXUnit — это не Gherkin
- Отладка падающего прогона, где шаг ЕСТЬ, но ведёт себя не так

## Инструкции

### 1. Найти шаг вместо сочинения

```bash
python skills/1c-vanessa-steps/scripts/search_steps.py --query "открыть форму документа" --top 5 --format human
python skills/1c-vanessa-steps/scripts/search_steps.py --category UI --subcategory Формы --format human
python skills/1c-vanessa-steps/scripts/search_steps.py --stats
```

Запрос — на русском, словами задачи. Вывод `--format json` удобен для обработки, `human` — для чтения.

**Критерий:** каждый шаг будущего сценария найден в реестре. Не нашёл — это сигнал, что действие нужно разбить на несколько шагов или написать свой шаг.

### 2. Проверить готовый сценарий

```bash
python skills/1c-vanessa-steps/scripts/validate_feature.py --file "features/МойСценарий.feature" --format human
```

Проверяет:
- Существование каждого шага в реестре
- Правильность аргументов шага
- Формат Gherkin-файла (Given/When/Then/And/But)

### 3. Статистика по библиотеке

```bash
python skills/1c-vanessa-steps/scripts/search_steps.py --stats
```

Показывает количество шагов по категориям и подкатегориям.

### Типичный workflow

```
1. search_steps.py --query "создать документ"     — найти подходящие шаги
2. search_steps.py --query "заполнить табличную часть" — найти шаги для ТЧ
3. Написать feature-файл из найденных шагов
4. validate_feature.py --file мой.feature          — проверить перед запуском
5. Запустить в Vanessa Automation
```

### Категории шагов

| Категория | Примеры |
|-----------|---------|
| UI / Формы | Открыть форму, нажать кнопку, заполнить поле |
| Данные | Создать документ, записать справочник, установить пометку |
| Проверки | Проверить значение, проверить сообщение, проверить состояние |
| Файлы | Записать файл, прочитать файл, сравнить файлы |
| База | Подключить TestClient, открыть базу, обновить конфигурацию |
| HTTP | Отправить запрос, проверить ответ |

## Лучшие практики

- **Ищи перед сочинением** — правдоподобное название ≠ существующий шаг
- **Проверяй перед запуском** — validate_feature.py ловит ошибки на этапе написания
- **Разбирай сложные действия** — вместо одного «сделай всё» используй последовательность простых шагов
- **Не дублируй** — если шаг уже есть, используй его, не создавай новый
