# Model Router Skill

## Правила выбора модели

| Тип задачи | Модель | Критерий | Стоимость |
|-----------|--------|----------|-----------|
| Код на русском | `opencode/mimo-v2.5-free` | Лучший русский язык, подтверждено тестами | $0 |
| Простые быстрые задачи | `opencode/nemotron-3.5-lightning-free` | Длина промпта < 500 токенов И НЕТ слов: спроектировать, оптимизировать, проанализировать, рефакторинг | $0 |
| Сложные задачи | `opencode/nemotron-3-ultra-free` | Длина промпта > 2000 токенов ИЛИ есть слова: спроектировать, оптимизировать, проанализировать, рефакторинг ИЛИ многошаговая задача (3+ подзадачи) | $0 |
| Фоллбек | `opencode/nemotron-3-ultra-free` | Primary модель упала 2 раза подряд | $0 |

## Алгоритм выбора

1. Оценить длину входного промпта (количество токенов)
2. Проверить наличие триггер-слов: `спроектировать`, `оптимизировать`, `проанализировать`, `рефакторинг`
3. Если есть триггер-слово ИЛИ промпт > 2000 токенов → выбрать `nemotron-3-ultra-free`
4. Иначе → выбрать `nemotron-3.5-lightning-free`
5. Если chosen модель упала 2 раза → переключить на `nemotron-3-ultra-free`
6. Если fast модель упала → попробовать ultra с тем же промптом

## Cost-Aware Routing (фаза 7.5)

### Приоритет по стоимости (от дешёвого к дорогому)
1. `nemotron-3.5-lightning-free` — $0 (быстрая, рутина)
2. `mimo-v2.5-free` — $0 (основная, качественная)
3. `nemotron-3-ultra-free` — $0 (запасная, глубокий анализ)

### Правила экономии
- Всегда начинай с самой дешёвой модели
- Масштабируй только если:
  - Модель вернула ошибку 2 раза подряд
  - Задача действительно требует более мощную модель
  - Пользователь явно запросил "максимальное качество"
- Логируй каждое переключение модели в `.memory/traces/model-switch.log`

### Формат лога
```
[timestamp] agent={agent} task={task_id} from={old_model} to={new_model} reason={reason}
```

## Примеры

- `анализ новостей "погода минск"` → lightning (коротко, нет триггеров)
- `проектирование REST API для системы авторизации` → ultra (есть триггер-слово "проектирование")
- `рефакторинг функции parse_json для ускорения` → ultra (есть триггер-слово "рефакторинг" И слово "ускорения" означает скорость)
- `напиши функцию расчета суммы` → lightning (простая задача)
