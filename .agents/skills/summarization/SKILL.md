# Summarization Skill

## Автоматическое сжатие контекста

### Стратегия: summary + archive

#### Порог сжатия
1. Если `.memory/activeContext.md` > 50KB → сжатие запускается
2. ИЛИ сжатие запускается командой `/sync` каждые 30 минут
3. ИЛИ по запросу team-lead

#### Алгоритм сжатия

**Шаг 1: Создание summary**
1. Прочитать activeContext.md
2. Извлечь главные пункты:
   - Последние изменения (что делали)
   - Текущие цели
   - Заблокированные задачи
   - Ключевые архитектурные решения
   - Статистика: сколько задач сделано/в работе/заблокировано
3. Составить summary в формате:
   ```
   # Summary YYYY-MM-DD
   
   ## Текущая сессия
   - **Что делали:** <основные изменения за последние действия>
   - **Цели:** <текущиеpriority-задачи>
   - **Заблокировано:** <проблемы и блокеры>
   - **Статистика:** <N задач сделано / M в работе / K заблокировано>
   
   ## Ключевые изменения
   1. <Изменение 1> — <короткое описание>
   2. <Изменение 2> — <короткое описание>
   3. <Изменение 3> — <короткое описание>
   
   ## Ссылки на архив
   - Подробный контекст сохранен в `.memory/archive/summary-YYYY-MM-DD.md`
   - Полный активный контекст восстановлен при необходимости
   ```

**Шаг 2: Архивация старого**
1. Переместить старый activeContext.md в `.memory/archive/summary-YYYY-MM-DD.md` (или полный дамп если размер < 100KB)
2. Создать новый activeContext.md с ссылкой:
   ```
   # Active Context (текущая сессия)
   
   Ссылка на полный контекст: `.memory/archive/summary-YYYY-MM-DD.md`
   
   ## Краткий обзор
   <выдержка из summary'а: 2-3 предложения>
   
   ## Текущие активности
   <самые recent изменения>
   ```
3. Очистить активный контекст, оставив только структуру и ссылку на архив

#### Автоматический триггер

```yaml
memory_compression:
  enabled: true
  max_size_kb: 50
  check_interval_minutes: 30
  auto_on_start: true  # при запуске агента проверять размер
```

#### Ручное вызова команда team-lead

```
/sync — принудительно Сжать контекст сейчас
/status — показать размер activeContext.md и флаг нужна ли сжатие
```

#### Восстановление из архива

При запросе агента на "полный контекст":
1. Чтение `.memory/archive/summary-YYYY-MM-DD.md`
2. Если нужно полное восстановление — чтение исходного файла из git history или backup
3. Обновление activeContext.md из архива
