# {name}

> Автоматически сгенерировано из шаблона проекта agent-hq.

## Структура

- `CONTEXT-BUFFER.md` — Шина контекста проекта (агенты пишут отчёты сюда)
- `KNOWLEDGE-BASE.md` — База знаний (паттерны, решения, библиотеки)
- `project.json` — Конфигурация проекта (тип, агенты, приоритет)
- `queue.json` — Очередь задач с приоритетами
- `memory/` — Память проекта (предыдущие контексты, артефакты)

## Использование

Этот шаблон копируется автоматически при запуске:

```powershell
.agents/scripts/create-project.ps1 -Name <name> -Type <type>
```
