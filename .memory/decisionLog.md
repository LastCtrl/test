# Decision Log — Журнал архитектурных решений

## ADR-001: Memory Bank (5 файлов)
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Нужна структура для хранения контекста между сессиями
- **Решение**: 5 файлов: activeContext.md, decisionLog.md, productContext.md, progress.md, systemPatterns.md
- **Альтернативы**: single-file (CRC),roach-style memory, external DB
- **Последствия**: Простой доступ, версионирование через git, параллельный доступ агентов

## ADR-002: Agent Communication Protocol (inbox/outbox)
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Агенты должны общаться между собой без прямого вызова
- **Решение**: JSON-файлы в .memory/inbox/{agent}/ и .memory/outbox/
- **Альтернативы**: REST API, message queue (RabbitMQ), shared DB
- **Последствия**: Простота, нет внешних зависимостей, trace через файлы

## ADR-003: Sandbox через git worktree
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Каждый агент должен работать в изолированном окружении
- **Решение**: git worktree для каждого агента в .agents/worktrees/{agent}/
- **Альтернативы**: Docker контейнеры, virtual env, отдельные репозитории
- **Последствия**: Лёгкий откат через git, изоляция веток, merge через PR

## ADR-004: Skills-first (подгрузка скиллов перед работой)
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Агенты должны использовать специализированные инструкции
- **Решение**: Каждый агент подгружает нужные скиллы через Skill tool перед работой
- **Альтернативы**: Встроенные инструкции, context injection, RAG
- **Последствия**: Переиспользование знаний, модульность, easy update

## ADR-005: Model Router (длина промпта + триггер-слова)
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Разные задачи требуют разных моделей
- **Решение**: Маршрутизация по длине промпта и триггер-словам (code, debug, test, etc.)
- **Альтернативы**: ручной выбор, cost-based routing,round-robin
- **Последствия**: Оптимизация скорости/качества, автоматический выбор

## ADR-006: Бесплатные модели
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Подписка opencode-go: лимиты 7/30 дней, 80% израсходовано за 3 дня
- **Решение**: Только бесплатные модели: glm-5.3-free (mimo недоступен: квота opencode исчерпана) (основная), nemotron-3.5-lightning-free (быстрая), nemotron-3-ultra-free (запасная)
- **Альтернативы**: платные модели (kimi-k2.7, glm-5.2, deepseek-v4-pro, qwen3.7-plus)
- **Последствия**: Ограничение возможностей, но стабильная работа в рамках лимитов

## ADR-007: Отказ от платных моделей
- **Дата**: 2026-08-21
- **Статус**: Принято
- **Контекст**: Все платные модели (kimi-k2.7-code, glm-5.2, deepseek-v4-pro, qwen3.7-plus) заблокированы из-за лимитов
- **Решение**: Не использовать платные модели до восстановления лимитов
- **Последствия**: Нужно адаптировать агентов под бесплатные модели

## ADR-008: RSS как основной источник новостей
- **Дата**: 2026-07-10
- **Статус**: Принято
- **Контекст**: news-bot нуждается в бесплатном источнике новостей
- **Решение**: Google News RSS (бесплатно, без API-ключа) как основной источник
- **Альтернативы**: Serper.dev (платный), Tavily (платный), DuckDuckGo (fallback)
- **Последствия**: Бесплатно, стабильно, но ограниченный функционал

## ADR-009: Отказ от LLM-слоя для простых запросов
- **Дата**: 2026-07-10
- **Статус**: Принято
- **Контекст**: analyzer.py: LLM возвращала пустой JSON для простых запросов
- **Решение**: Удалить LLM-слой для простых запросов, использовать _format_simple_list
- **Последствия**: Упрощение, надёжность, но потеря AI-фильтрации

## ADR-010: Прямой доступ к именованным агентам через task tool
- **Дата**: 2026-08-24
- **Статус**: Принято
- **Контекст**: FULL_PLAN раздел 8, ограничение №2 — task tool принимал только built-in типы, именованные агенты были доступны только через CLI-делегацию
- **Решение**: Все 19 именованных агентов доступны напрямую через task tool из build-сессии; ограничение снято
- **Последствия**: Упрощение делегирования, все агенты вызываются единообразно без дополнительных обёрток

## ADR-011: nemotron-3-ultra-free как модель всех проверяющих
- **Дата**: 2026-08-27
- **Статус**: Принято
- **Контекст**: opencode-go/ox-alpha-free упал ("Model not found") — проверяющие (qa-engineer, code-reviewer, security-auditor) остались без модели
- **Решение**: Все 3 проверяющих переведены на opencode/nemotron-3-ultra-free (запасная модель). 21 замена в 14 файлах (.opencode/agents/*.json, opencode.json, .agents/cards/*.json + index.json, AGENTS.md §1, README.md, FULL_PLAN.md, IMPROVEMENTS.md)
- **Альтернативы**: оставить на ox-alpha (упал), платные модели (запрещены §1)
- **Последствия**: Проверяющие на единственной запасной модели; тест после рестарта обязателен

## ADR-012: Протокол §3.1-3.3 — оценка времени, x2 timeout, верификация НЕ тимлидом
- **Дата**: 2026-08-27
- **Статус**: Принято
- **Контекст**: Не хватало дисциплины оценки задач, контроля зависаний и независимой приёмки
- **Решение**: §3.1 тимлид указывает оценку времени (5/10/15/20/30/45 мин) в каждом ТЗ; §3.2 при X×2 timeout — передача другому агенту на более сильной модели (лестница lightning→mimo→nemotron-ultra) без 2-й попытки; §3.3 верификация после каждой задачи — qa-engineer/code-reviewer, НЕ тимлид (исключение — проверяющие недоступны → базовая проверка тимлидом + эскалация)
- **Альтернативы**: ручной контроль (медленно), автоприёмка (ненадёжно)
- **Последствия**: Дисциплина времени и независимого QA; тимлид не пишет код кроме конфигов/документации/правок 1-2 строк

## ADR-013: cleanup-garbage.ps1 — автоочистка мусора репозитория
- **Дата**: 2026-08-27
- **Статус**: Принято
- **Контекст**: Накопление мусора (temp_*, *.bak.*, stray root agent JSON, пустые temp_*/ dirs) загрязняло репо
- **Решение**: Скрипт .agents/scripts/cleanup-garbage.ps1 — автоочистка по категориям, режимы -DryRun (по умолчанию, безопасно) / -Execute, идемпотентен
- **Альтернативы**: ручная чистка (ошибки), Git hooks (сложно)
- **Последствия**: Чистота репо; НО баг строки 94 — хардкод 3 имён проверяющих, остальные 16 stray не ловит → pending-задача dev-3 (трассировка источника + правка детекта ВСЕХ stray root agent JSON)
