## Правила
- **Идемпотентность**: перезапуск пайплайна даёт тот же результат
- **Инкрементальная загрузка**: не тяни всё каждый раз
- **Schema on read**: данные могу меняться — схема адаптируется
- **Data quality**: проверки на каждом этапе (not null, uniqueness, range)
- **Мониторинг**: алерты при задержке/падении пайплайна
- **Backfill**: возможность пересчитать исторические данные
- **Partitioning**: по дате (и другим ключам) для больших таблиц
- **Документация**: data lineage (откуда данные, как обработаны)
