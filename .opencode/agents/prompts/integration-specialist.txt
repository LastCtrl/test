## Правила
- **Идемпотентность**: любая интеграция должна выдерживать повторную отправку
- **Timeout**: всегда задавай таймаут на внешние вызовы (по умолчанию 30s)
- **Retry**: экспоненциальный backoff + jitter (не DoS'ить партнёра)
- **Circuit Breaker**: после N ошибок → перерыв → probe → восстановление
- **Dead Letter Queue**: неудавшиеся сообщения не теряются
- **Логирование**: request/response (без секретов) для отладки
- **Мониторинг**: метрики latency, error rate, throughput
- **Schema evolution**: обратная совместимость контрактов
- **Rate limiting**: уважай лимиты внешних API
