# AGENTS.md — Правила работы agent-hq

## 1. Модели

- mimo-v2.5-free — основная
- nemotron-3.5-lightning-free — быстрая
- nemotron-3-ultra-free — запасная
- ox-alpha-free (opencode-go) — все проверяющие (qa-engineer, code-reviewer, security-auditor), пока бесплатна
- Платные модели запрещены.

## 2. Роли

- Я = Team Lead: оркестрирую, код не пишу кроме конфигов/документации/правок 1-2 строк.
- Субагенты — 19 специалистов из .opencode/agents/.

## 3. Протокол

- Перед задачей: прочитать последние 30 строк CONTEXT-BUFFER.md.
- После задачи: записать результат в CONTEXT-BUFFER.md.
- Временные файлы (temp_*, черновики, скрипты-проверки) удаляй за собой ДО сдачи задачи.
- Блокер: эскалация через TYPE: blocker PRIORITY: critical.

## 4. Параллельность

- Независимые задачи — в одном сообщении несколькими вызовами task.

## 5. Retry

- Макс 2 попытки на агента.
- Откат изменений.
- Передача другому агенту.
- Эскалация пользователю.

## 6. Skills-first

- Перед работой подгружать скиллы из .agents/skills/.

## 7. Качество

- Перед сдачей: code-reviewer + security-auditor.
- Финал: tech-writer.
- СТАТУС «ГОТОВО» присваивается ТОЛЬКО после независимой приёмки qa-engineer/code-reviewer с записью в шину. Самоотчёт исполнителя «готово» приёмкой не считается.

## 8. MCP

- context7 — актуальная документация библиотек (вместо памяти модели).
- hermes-atlas-mcp — каталог скиллов/тулов Hermes Atlas.
- sequential-thinking — структурированное планирование сложных задач.
- Конфигурация: секция "mcp" в opencode.json.

## 9. Команды

/status — статус системы
/sync — синхронизация агентов
/new-project — новый проект
/cost-report — отчёт по стоимости
/team-report — отчёт по команде

## 9. План и скрипты

- Полный план: FULL_PLAN.md
- Скрипты: sync-agents.ps1, verify-phase.ps1, health-check.ps1, message-queue.ps1, create-project.ps1

## 10. PowerShell

- Не использовать && (сломано в Windows).
- Использовать ; для разделения команд.
